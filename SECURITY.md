# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.
Use GitHub's private vulnerability reporting instead: go to the Security tab of this repository and choose "Report a vulnerability".

I will acknowledge reports within 7 days.

## Supported versions

Only the latest commit on the main branch is supported.

## Secrets and data

This project is a static site that calls the public TVMaze API. It needs no API key, token or password, and it stores nothing on a server. Any key or secret found in the code or history should be reported privately as described above.
