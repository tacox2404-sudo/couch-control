# Style guide: Retro CRT / VHS neon

- **Mood**: 90s video-rental store at midnight. Dark CRT screen, glow, scanlines, tape labels.
- **Palette** (CSS variables): `--bg #0b0716`, `--panel #150d2b`, `--neon-pink #ff2e97`,
  `--neon-cyan #19f2ff`, `--neon-yellow #ffe14d`, `--text #e9e4ff`, `--muted #8a82b3`.
- **Type**: pixel/mono display font for headings and numbers; readable sans for body text.
- **Effects**: subtle scanlines and vignette, text glow on key numbers. Respect `prefers-reduced-motion`.
- **Components**: tape-label cards for shows, chunky arcade buttons, a screen "bezel" frame.
- **Copy voice**: short, dry, a bit cheeky ("Verdict: clear your weekend.").
- **Accessibility**: keep text contrast AA, visible focus rings, glow is decoration only.
