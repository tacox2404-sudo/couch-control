# Vision

**Couch Control** answers "what do we watch?" in two ways: by chance (Roulette) and by
curiosity (Explorer), with a fun reality check on the side (Binge-O-Meter).

Principles
- Fun first, but never a dead end: every fun result opens the full show page.
- The whole app is one shared link. No login, no key, no install.
- Every click is a real API call; the UI should make that feel instant (cache aggressively).

## Modes
- **Roulette**: slot-machine lever, random show, filters for genre / runtime / status.
- **Binge-O-Meter**: any show -> total hours, "weekends needed", rating curve per season, verdict line.
- **Explorer**: search shows and people, show page, cast, episodes, today's schedule, person credits.

## Out of scope (for now)
Accounts, watchlists stored server-side, streaming availability.
